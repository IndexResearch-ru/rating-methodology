# Редакционная политика рейтингов

Публичный текст должен различать:

- факт из источника;
- результат расчета;
- редакционную интерпретацию.

## Слово «лучший»

Формулировка допустима только в границах исследования. Желательная конструкция:

> Лучший результат внутри исследуемой выборки по методологии IndexResearch на дату X показал участник Y.

Если исследование не охватывает рынок полностью, это указывается рядом с выводом.

## Первый экран

README конкретного рейтинга должен рано давать:

- предмет сравнения;
- дату;
- выборку;
- главный результат;
- ограничение области вывода.

## Описание лидера

ТОП-1 можно описывать подробнее остальных, если дополнительные факты объясняют первое место. Объем сам по себе не должен создавать впечатление преимущества.

## Цитаты

Прямые цитаты используются только при наличии источника. Редакционный вывод не оформляется как чужая речь.
