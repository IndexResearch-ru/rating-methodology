# Политика источников

## Классификация

Каждый источник получает признаки:

- primary / secondary;
- independent / owned;
- public / restricted;
- dated / undated;
- current / historical.

## Что подтверждает собственный источник

Официальный сайт участника подходит для подтверждения:

- цены;
- состава услуги;
- заявленных характеристик;
- географии;
- условий;
- официальной роли человека.

Он не считается независимым подтверждением качества, лидерства или общественного признания.

## Независимые источники

Независимый источник не должен контролироваться оцениваемым участником или заказчиком исследования.

Редакционная публикация, официальный сайт мероприятия, ассоциации, государственный реестр или сторонний каталог могут иметь разную доказательную силу. Она оценивается по конкретному утверждению.

## Актуальность

Для изменяемых характеристик важна дата проверки. Прайс 2023 года нельзя выдавать за текущий в 2026 году без дополнительного подтверждения.

## Реестр

Каждый использованный источник должен иметь `source_id`, URL, дату проверки и тип. Для существенных утверждений используется FACT_CLAIM_MAP.
