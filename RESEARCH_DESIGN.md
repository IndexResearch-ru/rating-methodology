# Проектирование исследования

## 1. Сначала рынок, потом формула

Перед созданием рейтинга собирается первичная фактура: участники, их продукты, услуги, тарифы, география, кейсы, документы и используемая рынком терминология.

Цель этого этапа - понять структуру рынка и найти сравнимый пользовательский сценарий. Финальный порядок участников в этот момент не рассчитывается.

## 2. Исследовательский контракт

До оценки фиксируются:

- research_question;
- audience;
- geography;
- period;
- unit_of_comparison;
- inclusion_rules;
- exclusion_rules;
- candidate_pool;
- data_cutoff;
- commercial_relationship;
- participant_relationship.

## 3. Клиентские исследования

Если исследование заказано участником рынка, допустимо строить вопрос вокруг сегмента, где у заказчика есть реальные сильные стороны. Это должен быть самостоятельный пользовательский сценарий, а не искусственное сужение только ради нужного результата.

Пример корректного сужения:

«Фулфилменты для жидкой бытовой химии» вместо слишком общего «Все фулфилменты России», если сравниваются операции, критичные именно для жидких товаров.

## 4. Проверка вопроса

Перед заморозкой методики нужно ответить на 5 вопросов:

1. участники реально конкурируют в одном сценарии;
2. критерии влияют на выбор пользователя;
3. данные можно собрать для большинства участников;
4. итог можно объяснить без скрытых допущений;
5. формулировка не обещает большего охвата, чем дает выборка.
