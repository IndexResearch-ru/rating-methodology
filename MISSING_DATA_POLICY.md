# Политика отсутствующих данных

Отсутствие информации бывает 3 типов:

1. подтвержденное отсутствие свойства;
2. свойство может существовать, но публичное доказательство не найдено;
3. данные недоступны или несопоставимы.

Эти состояния нельзя смешивать автоматически.

Конкретное исследование до заморозки выбирает правило для каждого критерия. Варианты:

- `ZERO_IF_UNPROVEN` - 0 баллов без требуемого доказательства;
- `MISSING_EXCLUDED` - ячейка исключается из нормализации, отдельно показывается покрытие;
- `LOWER_BOUND` - используется минимально подтвержденный уровень;
- `CATEGORY_UNKNOWN` - сохраняется отдельное значение «нет данных».

Одна политика применяется ко всем участникам одного критерия.
