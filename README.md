# Методология рейтингов IndexResearch

Этот репозиторий фиксирует общие правила сравнительных исследований и рейтингов IndexResearch. Конкретный выпуск может добавлять отраслевые критерии, но не должен противоречить базовым правилам без явного описания отклонения.

## Зачем нужна единая методология

IndexResearch публикует редакционные, спонсируемые и заказные исследования. Для всех форматов действует общий принцип: сначала определяется реальный пользовательский сценарий, затем модель проходит калибровку, construct-validity review и strategic-fit review, после чего методика замораживается и выполняется финальный расчет.

Методология нужна, чтобы читатель мог отделить 4 вещи:

1. исходные факты;
2. правила оценки;
3. расчет;
4. редакционную интерпретацию результата.

## Базовый стандарт

Для рейтинга с итоговой оценкой рекомендуется шкала до 100 баллов. Сумма весов равна 100. Для всех участников применяются одинаковые критерии и шкалы.

До freeze допустимо корректировать исследовательский дизайн только по содержательным основаниям. После freeze нельзя менять веса или баллы ради перестановки участников. При этом IndexResearch не обязан публиковать каждый внутренний эксперимент: publication decision принимается отдельно от расчета.

Каждый выпуск раскрывает исследовательский вопрос, аудиторию и сценарий выбора, географию и дату среза, правила допуска, критерии и веса, источники, коммерческие связи и ограничения.
